# Каталог стилей и память повторов

С 19.11.2026 стиль картинки выбирает код, а не LLM. Раньше у каждого промпта была своя
таблица «Стили» (14–15 строк по 10 пунктов, строку выбирал `{random_category}`, пункт —
цифра seed). Теперь в user-части промпта стоит `{random_style}`, и при рендере на его
место встаёт одна строка из общего каталога `data/styles.json`:

```
Стиль: Nicolas de Staël (oil on canvas, palette knife; France, 1950s) — thick slabs of paint laid
flat with a palette knife, simplified blocks of colour, broad horizontal bands, muted greys with one
strong accent
```

## Почему так

- LLM плохо выбирает случайно: на просьбу «выбери любого художника» модель раз за разом
  берёт одних и тех же (Хокусай, Ван Гог, Моне). Старый промпт HiDream (до 17.11.2026)
  просил придумать 50 концепций и выбрать одну — в канале пошли повторы.
- Решает то, кого знает генератор картинок, а не LLM. Поэтому у каждого стиля есть видимые
  признаки (материал, линия или мазок, пространство, палитра): промпт описывает стиль ими,
  и картинка получается, даже если имя генератору незнакомо.
- Память повторов: стиль не повторяется у задачи год (`repeat_days`), ни у какой задачи —
  три дня (`global_days`), раздел каталога — три запуска подряд (`section_runs`); темы
  (`{random_theme}`) не повторяются в последних запусках (`theme_runs`, по умолчанию половина
  `max_theme`, не больше 25).

## Каталог

`data/styles.json` — около трёх тысяч стилей (2969): 52 раздела мирового искусства (от
средневековой миниатюры и икон до плаката, анимации, гравюры, ремёсел и исторической
фотографии) плюс стили прежних таблиц промптов. Собран Claude Opus 5.5 по разделам и
склеен с удалением дублей (`tools/styles_catalog.py`). Поля записи:

| поле | смысл |
|---|---|
| `id` | постоянный идентификатор (на него ссылается память) |
| `name`, `kind`, `medium`, `region`, `era` | как стиль называется в промпте, что это, техника, место, время |
| `features` | 18–40 английских слов видимых признаков |
| `fame` | 3 — общеизвестный, 2 — известный в истории искусства, 1 — узкий |
| `figurative` | 2 — изобразительный, 1 — стилизация, 0 — абстракция |
| `text` | стиль неотделим от надписей (плакат, комикс, карта, каллиграфия) |
| `suits` | темы, которые стиль передаёт убедительно: architecture, landscape, nature, objects, people, crowd, story, festival, north |
| `section` | раздел каталога |

Живых художников и действующих студий-брендов в каталоге нет (gpt-image на них отказывает,
а для публичного канала так правильнее), закрытых сакральных практик — тоже.

## Настройки задачи

`jobs.json`, `llm.styles` (без этого ключа задача рендерится по-старому):

| ключ | по умолчанию | смысл |
|---|---|---|
| `suits` | все | темы каталога, хотя бы одна из которых должна быть у стиля |
| `min_figurative` | 1 | абстракцию (0) задачи не получают |
| `min_fame` | 1 | 2 — только известные стили (для генераторов, не знающих имён) |
| `text` | `graphics` | `inscription` — стиль с надписями помечается `[надпись]` (qwen, dalle); `graphics` — «бери только графику»; `exclude` — не выбирать |
| `repeat_days`, `global_days`, `section_runs`, `theme_runs` | 365, 3, 3, ½ max_theme | память повторов |

Сейчас: hidream — architecture, ernie — nature, zimage — landscape, qwen — people
(+надписи), moss — objects, dalle — story (+надписи), qwen_chat — festival, yandex — north,
minimax — crowd.

## Память

Таблица `render_usage` в БД промптов (`storage/database/daily_images.db`): задача, вид
(`style`/`theme`), значение, раздел, время рендера. Запись делается при рендере — и для
заготовки (пакет Opus, вечерний Qwen4), которая может не пригодиться: такой стиль просто
пропускает свою очередь. Сбой памяти не мешает запуску: выбор идёт без неё.

Посмотреть, что выпадало:

```bash
sqlite3 storage/database/daily_images.db \
  "SELECT rendered_at, job_key, kind, value FROM render_usage ORDER BY id DESC LIMIT 30"
```

## Подпись к посту

С 19.11.2026 пост задачи с каталогом (`llm.styles`) уходит в Telegram с подписью — какой
стиль выпал:

```
🎨 Стиль: Томас Коул (Thomas Cole) — масло, холст; США, 1820–1840-е
```

Пайплайн находит стиль в отрендеренном промпте по началу его строки «Имя (техника;
место, время) — » (`styles.find_in_prompt`): так подпись верна и для заготовки, где
хранится только текст, и для промпта, переписанного после отказа модерации. Русские
название, техника, место и время — `data/styles_ru.json` (`{id: {name, medium, where}}`,
перевод Claude Opus); у художников в скобках остаётся имя в оригинале. Нет перевода —
подпись по-английски из каталога; стиль не найден — пост без подписи (предупреждение
в журнал). Отключить у задачи — `"publish": {"style_caption": false}`.

## Пересборка каталога

```bash
set -a; . ./.env; set +a
.venv/bin/python tools/styles_catalog.py sections   # разделы через Opus → storage/styles_raw/
.venv/bin/python tools/styles_catalog.py build      # склейка → data/styles.json
.venv/bin/python tools/styles_catalog.py translate  # перевод новых стилей → data/styles_ru.json
```

Перевод отдельным файлом пересборка не затирает; `translate` переводит только стили без
перевода.

Готовые ответы разделов не запрашиваются повторно (удалите файл раздела, чтобы обновить
его). `id` стиля выводится из имени: при пересборке у тех же стилей те же `id`, и память
продолжает работать.
